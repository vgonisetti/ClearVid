Privacy Policy for ClearVid

Last updated: September 2026

1. Overview
ClearVid is a privacy-first browser extension designed to purify and remove watermarks from Google Gemini generated media. 

2. Data Collection & Processing
ClearVid does NOT collect, store, transmit, or share any personal information, browsing history, account credentials, or user-generated media.

All image and video processing is executed 100% client-side within the user's local browser sandbox using standard HTML5 Canvas and WebCodecs APIs. No user files, media frames, or prompt contents are ever uploaded to any external server or third-party service.

3. Permissions
- "storage": Used solely to store local user preferences and cached offline history directly on your device.
- "downloads": Used solely to save the locally purified media files to your Downloads folder when requested.
- Host permissions ("gemini.google.com", "*.googleusercontent.com"): Used solely to detect media elements on Gemini and access media buffers locally for watermark removal.

4. Contact
If you have any questions regarding this Privacy Policy, please contact the developer via the Chrome Web Store support page.
